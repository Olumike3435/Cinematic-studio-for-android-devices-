# Cinematic Studio — Android starter prototype

This is a native Android Studio project scaffold for the first Cinematic Studio prototype.

## Included in this starter
- Dark, gold-accented CapCut-inspired interface
- Home, Edit, Templates and Profile tabs
- Android photo picker
- Live brightness and saturation adjustments on an imported photo
- Free-plan / optional-Pro information screen
- Responsive Compose layout for Android phones and tablets

## Important limitations
This is an early UI prototype, not a finished CapCut replacement. Video timeline editing, trimming, audio mixing, transitions, AI processing, saving edited exports, billing/subscriptions and Play Store release are not implemented yet. The filter chips currently select a look label; dedicated filter rendering is a later step.

## Build an APK
1. Install Android Studio on a computer.
2. Open this folder as an existing project.
3. Let Gradle sync. Use JDK 17.
4. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Android Studio will show the generated APK location.

Minimum Android version: Android 8.0 (API 26). Target SDK: 35.
